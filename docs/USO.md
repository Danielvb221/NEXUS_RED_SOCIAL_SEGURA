# Guía de uso

1. Configura las conexiones SQL y valida con `test_connection.php`.
2. Abre la aplicación en `index.php`.
3. Utiliza los módulos y acciones disponibles en la interfaz.
4. Las funciones de ETL dependen del notebook/API de Colab y de la configuración descrita en `ETL_COLAB.md`.
5. Usa datos ficticios para pruebas y no cargues información personal real en un repositorio público.

El sistema es un prototipo académico. Las capas ETL, Data Warehouse y predicciones que el README original identifica como demostrativas/pendientes no deben interpretarse como una integración completamente validada.
